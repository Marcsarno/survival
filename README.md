# Sarno Survive

A browser survival prototype set in a snowbound, post-apocalyptic South Florida. The power is gone. Leave the pavilion shelter, cross abandoned streets, a playground, the canal, the beach, a pharmacy lot and the pine woods. Bring back firewood and supplies, and keep the fire alive.

It is built with Three.js and Vite. The models come from free CC0 / CC-BY libraries, adapted in Blender, plus trees, palms, cars and a lantern generated by Blender scripts. There are no downloads or plugins for the player: it runs in a desktop or phone browser.

## Run it

Requires Node 20+ (tested with Node 24.19).

```bash
npm install
npm run dev
```

Open <http://localhost:5173>. Press **Start**, or **New game** to wipe the save.

For a production build: `npm run build`, then `npm run preview` serves `dist/` at <http://localhost:4173>. `dist/` is a static folder that can be hosted anywhere, including Vercel.

## Features

**Places.** Nine connected areas, every one reachable on foot. A loop runs north (street, Hibiscus Lane, pharmacy, service road, camp, woods) and one runs south (canal walk, beach), so return trips don't retrace the same path.

| Area | What's there |
|---|---|
| Pavilion Park | The shelter: tile-roof pavilion, stash crates, fire pit, low stucco walls, gates to the street, woods and canal path |
| Coral Palm Drive | Stucco houses with snowy barrel-tile roofs, boarded windows and garages, cars, mailboxes, palms, utility poles |
| Sunflower Tot Lot | Swing set, slide tower, climbing arch, a hiker's backpack on a bench, a chalk drawing, a stray dog |
| Hibiscus Lane | Side-street houses and an abandoned police cruiser with the pistol |
| Pelican Pharmacy | Parking lot, the frozen (zombies), medkits in the aisles, ammo in the stockroom |
| Service Road & Abandoned Camp | Tents, crates, an evacuation sign |
| Slash Pine Woods | Woodshed with split firewood and the axe, dead pines to chop down, fallen logs, the frozen pond, deer, foxes, rabbits, an owl at night, wolves late at night |
| Canal Homes | Backyards, patios and docks on the intracoastal, ice floes, ducks |
| Deerfield Beach Access | Sand and snow, dune fences, lifeguard stand, snack hut, driftwood |

**The resource loop.** You find supplies and firewood; your pack holds 10 items (16 with the hiking backpack). Carry them back and store them in the stash. The fire burns fuel all the time. Feeding it wood keeps the shelter warm, and warmth drains while you're outside, faster at night. Hunger empties over a day, so food matters. If you fall, you drop the pack where you fell and wake at the shelter; walk back to recover it (it's marked ✖ on the map).

**Shelter upgrades,** built from stashed or carried supplies:
- **Windbreak walls:** the fire burns 40% longer.
- **Firewood rack:** feeds the fire automatically.
- **Cot:** sleep until morning, fully healed; this also saves.
- **Lantern post:** keeps the frozen out of the park at night.

**Threats and combat.** The frozen wander, hear sprinting and gunshots, and at night can see your lit lantern from farther away. Aiming locks onto the nearest target and tightens while you hold it steady; a fully steady shot never misses. Ammo is scarce. The axe hits hard; unarmed you can only shove to break free.

**Wildlife and a companion.** Deer, foxes, rabbits and ducks flee when you get close and leave tracks in the snow. Feed the stray dog at the playground and it follows you, growls at the frozen, and waits by the fire.

**Details and discoveries.**
- Frozen iguanas fallen from the palms, pink lawn flamingos, and snowmen the neighborhood kids built.
- An emergency radio at the lifeguard stand; each turn of the dial gives a new broadcast.
- Chalk drawings and signs, and a lantern moving along the far canal bank at night.
- You can refill water daily at the ice hole in the pond.

**Guidance.** A short goals list sits under the clock: bring firewood, find the axe, search houses, check the police cruiser, and so on. The map (M) reveals areas as you visit them.

**Atmosphere.**
- A 24-minute day with dawn, day, dusk and moonlit night.
- Snow squalls that pass through: visibility drops, the wind rises, and the cold bites harder.
- A hand lantern with limited oil.
- Falling snow and fading footprints; the frozen and animals leave tracks too.
- Wind, footstep crunch, fire crackle, distant wolves and radio static, all synthesized.

**Other.** Progress autosaves in the browser: stash, upgrades, collected items, tools, the dog, and the time of day.

## URL options

- `?fresh=1`: ignore the save.
- `?autostart=1`: skip the start screen.
- `?quality=low` / `?quality=high`: phones default to low.
- `?shadows=high`: the lantern casts shadows (expensive).
- `?debug=1`: fps / position / draw-call overlay.
- `?dev=1`: developer shortcuts. F1–F9 teleport to areas and G gives supplies. These are for testing only.
- `?t=22`: start hour. `?at=x,z`: start position.

## Rebuilding assets

```bash
npm run fetch-assets
npm run assets
```

`npm run fetch-assets` re-downloads the source models and re-checks their licenses. `npm run assets` rebuilds every GLB with Blender 5.2 running in the background; append `-- pine-1 palm-2` to rebuild only named models. The script expects Blender at `C:/Program Files/Blender Foundation/Blender 5.2/blender.exe`; edit the `assets` script in `package.json` if yours is elsewhere.

To preview models without the game:

```bash
blender --background --python blender/render_sheet.py -- out.png public/assets/models/*.glb
```

## Automated playtest

```bash
npm run playtest
```

Starts a dev server on port 5199 and drives the game in Chromium with real keyboard, mouse and pointer input. It walks the routes, gathers, stores, fights, switches day and night, dies and recovers, and checks the touch layout. Results go to `playtest-output/results.json`; screenshots go to `docs/screenshots/`. Use `--headed` to watch, or `--only=woods,shelter` to run part of it.

See `docs/STATE.md` for what works, known issues and next steps, and `docs/DESIGN.md` for the decisions behind the design.
